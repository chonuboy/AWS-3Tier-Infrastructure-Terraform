# AWS 3-Tier Infrastructure using Terraform

Production-style 3-tier AWS infrastructure provisioned using Terraform.

## Architecture

The project provisions a secure and scalable AWS infrastructure consisting of:

- VPC
- Public and private subnets
- Internet Gateway
- NAT Gateway
- Application Load Balancer
- EC2
- Auto Scaling Group
- RDS MySQL
- IAM
- Security Groups
- Terraform
